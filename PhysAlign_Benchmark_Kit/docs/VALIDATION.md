原测试覆盖运算顺序、像素宽高换算、母题宏平均、引用闭合、坏记录影子依赖、重复目标、read 不计算、不从 Pass5 生成真值、来源改变失效、草稿搬迁等。外围测试覆盖过期/重复/非开发集审核条目、严格布尔确认、部分审核保留 pending 和禁止覆盖演示输出。

当前共 **118 项测试通过（62 + 11 + 45）**。新增测试还覆盖：

- 对 N=1..8 的所有合法 n/k，枚举真实无放回子集，与超几何上界计算逐项核对；区间准入用整数比较。
- 已隔离错误不从原发现数消失；附加风险不混进主样本分母；剩余上界先减确认坏母题数，再除剩余总体。
- 独立二审、漏检升级、完整母题准入、未抽样不伪造人审、系统性错误全规则阻断。
- 原样本不可重选、最多两轮、同一未修改候选不能换种子重试、已知错误及未抽样的受影响规则跨轮检查。
- 旧记录可导入但不能冒充随机审计；过期/冲突记录、缺确认、缺负责人签字被拒绝。
- 公共答案注入、私有文件混入 public、图片改动、发布根被改为 private，在重新计算目录清单后仍被重建校验拒绝。
- Windows 短暂 rename 拒绝访问的有界重试；已有目录不覆盖；分享清单刷新必须匹配旧哈希。

Windows 测试中遇到过源 fixture 发布时的瞬时文件占用；新发布层已有界重试。测试构建 26 母题的合成来源时，只对 fixture 的目录发布步骤使用同样的重试，未修改实际源转换器。

组员可按 README 重跑测试、校验文件哈希和合成示例。本轮没有在真实用户数据上伪造批准或生成真实 release，没有运行被测模型，也没有把模拟 DOM 测试冒充真实浏览器点击/视觉验收。测试不能替代物理语义审核，不能证明论文的必要对照或正式模型评测已完成。

`KIT_MANIFEST.json` 用于发现缺文件或版本混用，不是经过签名的发布认证。它与代码一起被修改时，不提供对恶意篡改的独立真实性保证。

Windows 深层临时目录的解压测试触发过 WinError 206；改用短根目录后通过。因此 README 明确要求使用短解压/输出路径。这是已知路径长度限制，不声称支持任意深度目录。
