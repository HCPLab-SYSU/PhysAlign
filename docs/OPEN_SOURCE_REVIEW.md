检查日期：2026-09-27。范围包括 PhysAlign 主框架、新加入的
`PhysAlign_data_build/`、Benchmark Kit 以及三者的接口。

代码与数据边界已整理到可以开始编写 README 的状态。正式对外发布前，仍需由维护者

## 已完成的修复

- Pipeline 测试改用临时合成工作区，删除依赖旧实验存档的测试。
- 提供可重建的合成 PNG，避免示例 SVG 无法被 Pillow 和图片处理链路读取。
- 安装包使用独立的 `physgraph_legacy` 包名，避免覆盖主框架的 `scripts`；源码目录下
  的原有脚本入口保留。wheel 包含提示词、Schema 和审核 UI，sdist 包含测试辅助文件。
- 修复 Windows 运行锁的进程存活检查。Windows 下 `os.kill(pid, 0)` 不具有 POSIX 的
  探测语义，改用只读进程查询，并以独立子进程回归测试确认不会终止目标进程。
  依据：[Python 的 os.kill 文档](https://docs.python.org/3/library/os.html#os.kill)。
- 导出要求 Pass 1–4 全部批准、审核哈希匹配、严格校验通过、切分已确认且图片哈希一致；
  已排除的题目不能进入导出。`prepare --force` 不允许改变题目后沿用旧审批。
- 工作区迁移验证图片与源文件哈希，支持数据目录移动后的源文件推断，不再保留旧机器
  的绝对路径作为迁移元数据。
- 审核服务器校验 Host、Origin 和 JSON 请求类型，默认只监听本机；远程绑定需要显式开关。
- 数据 ID 拒绝 Windows 保留文件名和大小写冲突。
- 发布扫描覆盖候选源码及可读取的 Git 暂存内容，检测密钥格式、个人主目录、邮箱、
  敏感文件名和意外二进制；存在 Git 仓库却无法读取索引时不能通过检查。
- Benchmark Kit 正确解析 Pipeline 的工作区相对媒体路径；重建 Kit 合成示例并更新
  文件清单，保持示例与当前转换器的实现哈希一致。
- 移除 Pipeline 中无提交、无分支、无远程地址的独立 Git 元数据，源码作为普通子目录
  保留；补上根目录 CI，覆盖主框架、Pipeline、Kit、前端逻辑与安装包检查。
- 根目录 Git 属性保留冻结示例和 Kit 的原始文件字节，防止跨平台换行转换破坏哈希。
  已验证启用 `core.autocrlf=true` 时，相关样本的 Git 暂存字节与文件原文一致。
  根目录忽略规则同时覆盖本地数据、工作区、导出、凭据文件与 `*.local.json`。

本地验证使用 Windows、Python 3.12、Node 24。CI 已配置 Linux/Windows；尚未在远程
GitHub Actions 上执行。模型相关测试使用替身或 dry-run，没有发送真实付费 API 请求，
也没有测试真实模型的标注质量或 GPU 推理效果。合成测试中的批准状态不是正式人工审核。
上述五组 Python 测试合计 460 项全部通过；sdist 的重复验证不另计入总数。

公开候选文件包含代码、合同、提示词、文档与合成素材；自动扫描按规则检测，不能替代
维护者对知识产权归属、素材授权与最终提交范围的确认。`exports/` 中的图仍可能包含
使用者自己的题目来源、图片路径及审核者信息，它不是可以无条件公开的数据包。
