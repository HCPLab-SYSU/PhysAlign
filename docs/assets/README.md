# README assets

The scientific illustrations are taken directly from the author-provided PhysAlign manuscript, **PhysAlign: A Benchmark for Evidence-Grounded Role Alignment in Multimodal Physics Reasoning**. They are not redrawn or generated illustrations.

| Asset | Source | Export |
| :--- | :--- | :--- |
| `figure-1-grounding.png` | Figure 1, manuscript page 2 | Original figure region rendered at 432 dpi; 2,142 × 966 pixels |
| `figure-2-pipeline.png` | Figure 2, manuscript page 4 | Original figure region rendered at 432 dpi; 2,358 × 1,302 pixels |

Only the surrounding page furniture and captions were cropped out. The artwork, labels, colors, and scientific content were preserved. Captions in the root README identify the original figure numbers. The full manuscript and its review headers are not included as public documentation assets.

For the supplied 612 × 792 pt manuscript pages, the crop rectangles in PDF points are `(128, 83, 485, 244)` for Figure 1 and `(107, 84, 500, 301)` for Figure 2. The figures were rendered with PyMuPDF at a scale of 6. New manuscript layouts require checking these bounds again.

The two `badge-*.svg` files are local navigation assets generated by `scripts/build_readme.py`. The root README uses compact shields-style resource and model badges for its public header.
